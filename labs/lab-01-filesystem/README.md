# Lab 01 — Filesystem

## What I did
Today I practiced filesystem basics
create nested folders with mkdir -p, made files with touch, copied stuff with cp and cp -r, renamed with mv, and practiced safe deletion with rm -rf

## What went wrong
First time i ran cp -r, the destination path confused me a bit - wasn't clear which folder was going where.

## How I fixed it
Checked pwd and ls to see where i was, then gave the right path
Now i make it a habit to check pwd + ls before running any destructive command.

## What I learned
mkdir -p can make nested folders in one go - for a/b/c you don't have to run mkdir three separate times also, checking pwd before rm -rf is a must.
