# Day 1 — Linux Filesystem

Learned about the filesystem today—specifically, the purpose of each folder
- /etc = config files
- /var, /var/log = runtime data and logs
- /tmp = temporary stuff
- /home = user's personal space
- /proc = system/process info
- /dev = devices

understood paths—absolute vs relative, along with commands like pwd, cd, ., .., and ~

practiced commands: ls, mkdir, mkdir -p, touch, cp, mv, rm, ls -a

Tried out globbing too: *, ?, [] — such as *.log, file?.txt
Realized the importance of verifying the pattern before running destructive commands.

Made a mistake—got confused between creating a directory and a file using mkdir,
and also had a misconception regarding globbing with hidden files Both points are now clear.
